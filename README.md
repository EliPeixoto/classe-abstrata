# Classe Abstrata
----
### Exercicio

- Crie uma classe Account para representar uma conta bancária. Esta conta deve ter um saldo (balance).
- O saldo inicial deve ser fornecido no momento em que a conta é criada.
- Crie também as classes CheckingAccount e SavingsAccount, para representar uma conta corrente e uma conta poupança, respectivamente.
- Defina um método updateBalance(), que calcula o novo saldo da conta. O cálculo deste saldo é feito através de um ganho em porcentagem sobre o saldo atual. O valor exato desta porcentagem é calculado de forma diferente em cada tipo de conta.
